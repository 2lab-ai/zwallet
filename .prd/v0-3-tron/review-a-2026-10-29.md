## Findings fixed

1. The main branch added transaction-limit lookups after the draft changed `evm::config`
   to return `Result`. Both lookups now handle a non-EVM family without panicking or failing
   compilation. Token-registry lookup for a Tron chain returns false.
2. New `native-cap` and `calldata-cap` commands could sign Tron policy metadata before a
   Tron signer existed. The public native/token/calldata cap paths now refuse before the
   password, with the same guard as Tron fee caps and payees. The expanded CLI regression
   was observed RED (a `native-cap` operation wrote `maxNativeWei` for Tron), then GREEN.
3. A node could echo RPC credentials into a wrong genesis id, account address/balance,
   owner-permission warning or token symbol. Diagnostic and display values now redact the
   endpoint credentials before escaping. A mock-node regression was observed RED
   (`credential leaked from block`), then GREEN across all five fields.
4. A successful request wrapper with `contractRet: REVERT` and a 32-byte result was accepted
   as a balance. The decoder now rejects failed or malformed execution results separately
   from request acceptance. The regression was observed RED (USDT balance 5), then GREEN.
5. README conflicts were resolved in favor of the main branch's documentation layout.
   Tron usage is in `docs/commands.md`, derivation in `docs/security.md`, and the README and
   feature table distinguish working reads from planned signing/transfers.
