## What changes for users
- **`s` makes the selected key the active one.** The TUI asks first, and only `y` confirms. Any other key says no, and Ctrl-C says no and quits.
- **A refused make-active is shown whole.** Example: another process contradicts the key's cached address. The key pane then stops with the whole error, wrapped, and nothing becomes active.
- **The not-verified note follows the trust state (A1).** The key list and `list` show it with the bar's trust. Locked and unverified keys get it too, and an impostor's warning stays on the line above it.
